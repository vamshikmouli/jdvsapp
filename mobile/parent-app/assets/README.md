# App assets

Add these PNGs before an EAS build (they're optional for Expo Go dev):

- `icon.png` — 1024×1024 app icon (reuse the school logo).
- `splash.png` — splash image, transparent, ~1284×2778 safe area.
- `adaptive-icon.png` — 1024×1024 Android adaptive foreground.
- `notification-icon.png` — 96×96 white-on-transparent for Android notifications.

`app.config.ts` references these paths.
